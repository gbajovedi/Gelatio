# Regras de Git (Commit e Push)

- **Janela de Horário para Git Commit e Push:**
  - **Segunda a Sexta-feira:** Permitido **apenas após as 19h00** (horário local).
  - **Sábados e Domingos:** Permitido **em qualquer horário**.
  - *Antes de executar `git commit` ou `git push`, sempre verificar o dia da semana e o horário local.*

- **Diretrizes Permanentes e Invioláveis:**
  - **NUNCA modificar o arquivo `README.md`**.
  - **NUNCA mencionar nomes de autores ou referências informais** em mensagens de commit, comentários de código, documentações, testes ou relatórios.
  - **Garantia de Qualidade:** Antes de qualquer commit, rodar sempre `vitest run` e `tsc --noEmit` para garantir 100% de integridade.
